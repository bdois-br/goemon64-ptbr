# Changelog

## 0.8.52 — FILE 05F + Barra de Energia SAFE

Build pública de referência do projeto.

- correções adicionais de diálogos com retratos no FILE 05F;
- preservação das correções de retrato dos FILE 067, 069 e 074;
- correção pontual da mensagem da Barra de Energia;
- preservação da proteção contra crash em caixas nativas de 9 rows;
- preservação do reflow, fonte PT-BR, acentos, cursor e casos especiais já estabilizados.

## Histórico de desenvolvimento

O projeto passou por dezenas de builds experimentais. As versões 0.8.40–0.8.46 foram descartadas após regressões em diálogos sensíveis. A linha de desenvolvimento voltou à base estável 0.8.39 e prosseguiu com mudanças mais isoladas e seguras até a 0.8.52.
